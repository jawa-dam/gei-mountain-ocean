## How to use with Hostinger Builder
1. Upload this repo to GitHub
2. Enable GitHub Pages (Settings → Pages → Source: main / root)
3. Copy your Pages URL, e.g. `https://YOURUSERNAME.github.io/gei-mountain-ocean/`
4. In Hostinger → Add Element → Embed → paste:

```html
<div style="width:100%;max-width:420px;margin:0 auto;">
  <iframe
    src="https://YOURUSERNAME.github.io/gei-mountain-ocean/"
    style="width:100%;aspect-ratio:9/16;min-height:680px;height:760px;border:3px solid #b8d4ea;border-radius:24px;overflow:hidden;"
    scrolling="no"
    loading="lazy"
    allow="fullscreen">
  </iframe>
</div>
```

Set the Embed element height to 760px in Hostinger.
